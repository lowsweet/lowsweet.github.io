The Landing adds a local galaxy-twinkle.js extension to the existing galaxy scene at runtime. A sparse halo layer reuses 240 existing particle positions with locally authored shaders and seeded, independent brightness cycles. The halo extension wraps the native photodisc's basic shader in memory, applying masked, seeded UV flow and gentle breathing to its warm outer haze. The prior index-0-only extension did not animate this broad haze and has been replaced. A separate runtime extension to the native particle material adds spatially phased breathing to warm-colored particle halos, with masked texture sampling and brightness changes confined to their outer glows. The white nucleus, blue outer arms and native lens flare are protected; native particle positions, sizes, color data and original texture files remain unchanged. The background bridge also normalizes resize dimensions to prevent the old helper from multiplying the renderer's pixel ratio twice. The standalone native clone does not install these extensions. Original rendering scripts and shader files remain unchanged.

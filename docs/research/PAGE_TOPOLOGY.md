# LinkeAI 页面结构与依据

## 公开页面观察
来源 https://cc888.ai/zh-CN 与 https://cc888.ai/home?menu=zhinengti；调研于 2026-10-09。
首页八区块：星河为幕、退居星轨、同一批星辰、四种形态、聚散有时、星尘之作、最后一个形状、注册与页脚。
原站前景为正常文档流，透明区块覆盖固定画布。导航包含 LinkeAI、客服、API开放平台、开始使用、中文。首屏左下文案、右侧模型示例。
实际 1390×1186 视口：区块高度依次 1187、629、1187、617、597、553、1187、545 px。首屏横向 padding 5vw，标题约64 px；后续标题35–50 px。原站字体 Inter / PingFang SC / Microsoft YaHei。
工作区公开观察覆盖45智能体、模型四种类型、灵感、帮助、API文档、排行榜。

## 用户指定替换
保留全部首页前景结构，背景采用截图的低角度斜视银河，左下到右上，暖白核心和蓝紫星尘。所有动态业务数据 mock。
画布固定、pointer-events:none。原生滚动控制镜头，首屏距离1.00，最终0.18，上滚反向。手机低粒子，WebGL失败与减少动态偏好静态降级。

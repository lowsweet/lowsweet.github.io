# 首页与银河规格

以下为2026-10-11最新用户反馈后的规格，覆盖最初八段内容要求。工具工作区继续暂停。

- 首页实现位于`components/landing/`，中英文案以`lib/landing-i18n.ts`为准。
- 首屏标题保持“把所有 AI 的能力 / 聚成同一片星河”，全部白色。说明改为“在一个工作台中使用主流 AI 模型和创作智能体，完成对话、写作、图像、视频与音频创作。”
- 英文说明为“Use leading AI models and creative agents in one workspace for chat, writing, images, video, and audio creation.”
- 首屏文案与开始使用按钮随整屏进度轻缓退场，返回时恢复；被动scroll监听与rAF合并测量，200ms指数跟随平滑进度，smoothstep控制淡出与第二屏渐入。首屏文案以78%位移抵消快速上滑，第二屏等首屏足够淡后才显示，避免标题重叠；隐藏时设置inert，导航不参与。静态与减少动态直接使用实际进度、不增加位移。
- 完整删除`retreat`区块及其占位、翻译和DOM镜头锚点。首屏直接接“主流模型，一个入口”。
- 当前区块顺序：`opening`、`doorway`、`capabilities`、`inspiration`、`signup`。
- 对应区块距离为`[1, .74, .60, .35, .18]`；按实际section位置插值，resize与图库加载后重算锚点。首屏至模型星群采用一段连续的比例缩放，跳过该段内部`.88`停靠点的二次减速；其余滚动路线保留。
- 背景使用完整本地Stars渲染器和运行时扩展。入场2.5秒自转、1秒连续拉远；随后固定`rx=π×.05`、`ry=5.20`，滚动只缩放至太阳并沿原路返回。
- 每个内容屏至少100dvh（100svh兼容回退）、首屏文案左下，导航固定；品牌只用LinkeAI文字。API、商务、客服和语言入口沿用现有布局。
- 控件使用Beautiful UI中性色规范，保留当前开始使用按钮特效；不添加蓝色强调、装饰性AI图标、本地演示徽章或文字后黑色遮罩。
- 首页支持中文和English；文案、图库、流星名称和弹窗同步切换，语言偏好持久化，切换不重播银河入场。
- 流星仅在首屏，暖白＋香槟金＋淡紫，围绕左下文案落点；离开首屏和切后台时暂停，卸载后清理定时器。
- 原生滚动与固定画布保持正常点击；390px、768px、1440px布局不允许横向溢出。减少动态或WebGL不可用时使用现有静态银河。
- 原始Stars脚本、着色器和资源保持原样，独立副本保留原生Tour；本地集成仅修改首页适配层。
- 验证使用`npm run typecheck`、`npm run build`和`node scripts/verify-stars-source.mjs`，实际浏览器记录保存在`docs/design-references/`。

## 第二屏模型星群（2026-10-11）

- 左侧文案与首屏对齐，宽度约380px；标题“主流模型，一个入口”，正文“自由切换模型，完成对话、图像、视频与音频创作。账号、积分和历史记录统一管理。”英文同步更新。
- 整个Landing的SectionLabel及装饰短横线已移除，保留正式标题和卡片功能标签。
- 首屏与第二屏使用共享LandingStartButton，样式、动态填充、文案和/app跳转相同。
- ModelConstellation接收本地化50个模型及13个品牌图标，桌面/平板/手机最多8/6/4个。900px以下改为上下布局，手机星群高300px。固定种子888产生落点偏移、尺寸、周期与峰值差异，名称最多两行。
- 模型落点改为围绕第二屏中央星群的椭圆，按左侧文案与顶部导航避让；900px以下在独立星群区域内环绕排布。手机名称12px，图标保留品牌色。位置在滚动及模型轮换时不移动，窗口或文案尺寸变化时重新计算。
- 光点周期3.5–6.5秒，名称轻微提亮且始终可读；8–12秒暗相位换名，100ms淡出+100ms淡入。名单洗牌用完一轮再重排，同屏不重复，替换不改变落点。独立组件不调用流星代码。
- 离屏或document.hidden时冻结CSS动画与逻辑时钟，恢复不补播；减少动态或静态模式固定展示。卸载清理rAF、观察器与事件；语言切换保持模型ID、位置和时钟。

## 整屏滚动吸附（2026-10-11）

- 整个Landing使用原生CSS Scroll Snap，平滑切换后对齐一个完整区块，不停在两屏之间。五个区块保留；signup与footer组成最后一个吸附区域。
- 区块最小高度随实际视口高度变化，较短内容居中。内容超过视口时允许在该区块内正常滚动，读完后再吸附到下一个；不裁切手机长文案、卡片或页脚。行为依据[CSS Scroll Snap规范](https://www.w3.org/TR/css-scroll-snap-1/#snap-overflow)。
- 仍使用window的原生滚动；不接管wheel、touch或键盘事件。银河锚点由现有ResizeObserver计算，镜头随实际scrollY缩放，固定旋转角度。作品瀑布流在同一个较长区块内纵向阅读。
- html上的吸附类仅在Landing挂载期间存在，进入/app后清除。强制静态及系统减少动态时scroll-behavior为auto；页面对齐仍启用。
- 流星层的ResizeObserver写入移到下一动画帧，滚动与resize共用合并测量，避免更改被观察高度时产生重复尺寸通知。卸载同时取消尚未执行的测量帧。
- 实现：components/landing/landing-scroll.css、landing-page.tsx；实际过渡记录：docs/design-references/landing-screen-snap.mp4。

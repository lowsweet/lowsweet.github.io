# 工作区布局重组（2026-10-11）

按用户确认的 cc888.ai/home 工作台结构重组本地 `/app`，首版采用项目已有 Beautiful UI；随后按用户选择接入 Lobe UI 官方组件与主题。界面改动限定在 `components/studio/`，另增加所需依赖；Landing、原始银河资源、模型目录及 MockService 数据结构保持原值。

## 布局与操作

- 默认进入大模型并选择本地目录的 Suno V5。左侧顶部切换大模型、智能体、灵感广场与开放 API；下方为分类、厂商、搜索、收藏/置顶和独立滚动工具列表。
- 保留24个本地模型和45个智能体。模型显示 Lobe 品牌图标，单色图标随主题变化；Suno 保留本地品牌图标。模型选择统一由左侧目录完成。
- 中央直接显示当前模型、介绍、会话或生成结果。出现结果后收起大幅介绍，为预览腾出空间。
- 输入区固定在中央区域底部。常用参数直接展示，完整参数、记忆与技能通过“更多设置”访问。附件、历史对话、预览、下载和再次使用沿用现有mock逻辑。
- 智能体直接进入当前工具，保留需求、阶段确认、编辑、版本和项目流程。任务列表位于顶部，素材、项目、账号和帮助保留可访问入口。
- 手机目录使用抽屉，选择工具后收起。URL继续支持模型、种类、智能体、项目和提示词；项目恢复使用MockService最新状态，避免新建后旧状态闭包找不到项目。

## Lobe UI 接入（2026-10-11）

使用 `@lobehub/ui@5.57.3` 的 Base UI 控件和 `@lobehub/icons@5.23.0`。配套依赖为 antd、antd-style、motion。按组件路径导入，限定在工作区路由；Lobe 的文档级全局样式和在线字体加载关闭。

- `lobe-ui.tsx` 提供 ConfigProvider → ThemeProvider，并把官方语义 token 映射到原工作区变量。深浅色来自同一个主题系统，菜单、选择器、弹窗与抽屉保留官方 Portal 的主题上下文。
- 侧栏分类、搜索、厂商筛选，以及工作台按钮、输入框、选择器、页签、开关、复选框、滑块、进度条与弹窗使用实际 Lobe UI 控件。保留原功能结构与 mock 处理函数。
- 官方按钮参考：[Base UI Button](https://ui.lobehub.com/components/base-ui/button)。实测默认按钮高度32px、圆角6px、左右内边距14px。工作区沿用其原生状态和中性色；品牌图标保留品牌色。
- 模型列表压缩为名称与一行说明；工作区主面板单独滚动，输入区保持底部位置。手机使用 Lobe Drawer，选择模型后收起；详情与素材弹窗使用底部操作区。
- 同步修正音频预览、代码输入、智能体表单与画布中遗留的固定深色底和蓝色装饰，改用主题语义色。原始图像及品牌资产不重着色。

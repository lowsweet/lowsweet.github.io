## 管理与开放平台

- 灵感：作品分类、搜索、详情、提示词、收藏、同款创作、我的作品与使用记录，本地作品发布。
- 素材：本地导入、预览、重命名、删除、下载、跨工作台引用。
- 项目：新建、编辑、复制、回收站/恢复、版本选择和历史恢复。
- 任务：阶段进度、日志、等待审批、暂停/继续、取消、失败重试。
- 开放平台：接口目录、请求代码、模拟响应、演示密钥、调用日志、价格与排行榜；11 个工具接入示例和 WorkBuddy 图像技能说明。
- 账号：本地登录/注册/退出、演示积分充值与账单、主题/语言/隐私遮罩、记忆和技能偏好。
- 帮助：公告、新手流程、FAQ 与本地反馈记录。

## 数据架构

AgentDefinition → Project → Task / Version / Asset，以 ID 关联。统一 MockService 操作；IndexedDB 保存状态和文件，localStorage 保存偏好。没有真实模型、第三方支付、外部消息或系统安装调用。三个可选 WebMCP 工具只读取目录/项目或创建本地草稿。

# LinkeAI 本地 Demo

## GitHub Pages

网站：<https://lowsweet.github.io/>。源码在 `main` 分支，静态发布文件在 `gh-pages` 分支；GitHub Pages 自动发布该分支的更新。

```sh
npm ci
npm run build:pages
```

导出位于 `pages-dist/`，包含首页、`/galaxy/`、`/app/` 和全部本地动画素材。此构建独立于原有 Vinext 开发与 Cloudflare 构建，不需要在线后端；工作台继续使用浏览器本地演示数据。

更新源码与网站：

```sh
git add .
git commit -m "Update LinkeAI"
git push origin main
npm run deploy:pages
```

`deploy:pages` 重新构建并更新 `gh-pages`，需要当前电脑已登录 GitHub 且有仓库写入权限。首次拉取后本地开发仍使用 `npm run dev`。截图和验收录像保留在原电脑，不随代码提交。

**当前交付：新版 LinkeAI 首页已接入 Noomo 完整视觉旅程；原银河版保留在 `/galaxy`。工具工作区开发继续暂停，现有 `/app` 保留。**

新版首页使用原站 Nuxt/Vue、Three.js r179、玻璃材质和完整镜头时间轴，通过同源 iframe 隔离。凤凰飞行、羽毛、渐变叙事、四颗能力晶体、声音、材质变化和结尾火焰均保留。原银河版仍使用 Stars 原始渲染器，滚动只缩放。工作区使用 Beautiful UI 的视觉规范，覆盖 45 个智能体、24 个模型、素材与项目管理，以及模拟 API / 账号流程。

## 演示步骤

1. 新版首页点击开始探索，沿凤凰、感官章节和羽毛滚动到四颗晶体；悬停或点击进入能力详情，返回保持位置。重塑凤凰改变材质，声音开关控制本地音轨。页脚进入银河版；银河版自转2.5秒、拉远1秒，后续滚动只缩放。
2. 点击“开始使用”，搜索“品牌 VI”，填写需求，确认品牌访谈，选择并锁定 Logo，再延展物料。
3. 体验“小说工作室”的世界观、大纲和章节；编辑正文、保存版本，然后导出 Word 或文本。
4. “故事成片”确认角色、场景、分镜、首帧与声音后，预览本地视频与音轨，下载 ZIP。
5. 生成时开启“模拟失败”，体验重试；运行过程中刷新，任务自动暂停，点击继续恢复。
6. 模型区体验对话、图像、视频和音频；选择本地文件或引用素材，结果会出现在素材库。
7. 无限画布拖动、连线和编辑节点，保存后刷新恢复；多模型协作比较多个回答并汇总。
8. 开放平台用演示密钥进行模拟调试，查看响应、日志、模型价格和排行榜；账号页模拟充值并检查消费记录。

## 数据与文件

- 默认已登录演示账号，初始 1000 积分。所有业务调用、积分、充值、安装、注册和联系流程均在本地模拟。
- 项目、任务、素材 Blob、会话、版本、积分记录、密钥与反馈保存在 IndexedDB；偏好保存在 localStorage。
- 执行中的任务刷新后暂停，不会静默继续生成或扣分。
- Word / PPT / 文本从当前选择的编辑版本导出；图片、12 秒音乐及 720p 视频为固定本地样例。
- 支持真实文件选择、预览、下载和工作台间引用。单个文件限制 100 MB。
- 手机与桌面采用同一原站渲染层；减少动态偏好或 WebGL 不可用时显示静态银河。
- 首页支持中文与英文，切换后正文和弹窗同步更新；工作区英文偏好切换导航。

## 完整 100,000 Stars 本地副本（银河版）

启动开发服务后打开 `http://127.0.0.1:5173/stars-clone/index.html`。左上角播放按钮运行原始完整 Tour；鼠标/触屏旋转、右侧尺度滑杆、恒星名称、光谱热力图、声音及说明控件保留。银河、119,617 颗恒星、太阳系、奥尔特云、太阳表面、日冕和天空盒均使用原站代码及本地资源。

银河版 `/galaxy` 嵌入同一份完整渲染器，隐藏原站控件，保留 LinkeAI 内容。入场完全退出 Tour：起始镜头2000、rotateX=π×.05、camera.scale.z=.83，固定镜头尺度自转2.5秒，然后用缓入缓出的曲线在1秒内拉远至50000距离。旋转与拉远共享一条连续时间线，拉远期间保持旋转，在最后250ms减速，到rotateY=5.20的斜向银河后停止。首页拉远沿用原版handleMWheel的比例缩放公式；相机立即跟随时间线，保证实际移动1秒完成，不额外追加原版跟随收敛的尾部时间。拉远采用五次缓动，在起止点速度和加速度均为零，避免末段急停。提前滚动仅记录进度，完整入场完成后用原版相机跟随平滑接入当前位置。首页滚动沿原始停靠点的距离经过恒星和太阳系，最终到太阳；反向沿同一路线返回。入场后观察角固定在rx=π×.05、ry=5.20，滚动只影响镜头距离，不再插值Tour的旋转角度，角速度保持为零。`?motion=static` 保留静态降级。

资源出处与原始 SHA-256：`public/stars-clone/full-upstream-manifest.json`。本地集成文件：`local-bridge.js`；原站全部 36 个 JS 与 16 个着色器保持原样。旧 `scene.html` / `scene-adapter.js` 是早期局部移植，当前首页已不使用。工具工作区继续暂停。

入场配置位于 `lib/galaxy-config.ts` 的 `GalaxyEntranceConfig`。场景阶段与实际姿态通过同源消息上报，并保存在 `.galaxy-scene` 的 `data-galaxy-phase` / `data-camera-*` 属性中。原版引擎、着色器文件与素材未修改；入场桥接层不调整曝光或银河旋转矩阵。首页的星核光晕仅在运行时扩展材质。

首页背景禁用原站 `#layout` 的启动CSS缩放（125%→100%），从首个可见星海帧开始保持画布尺寸不变；独立原版副本仍保留该效果。

首页从原有银河粒子中固定选取240个位置，增加清晰星心与柔和光晕，使用GPU计算约2.2–5.2秒的独立周期，从暗到亮再淡下去，让变化在静态星尘贴图上也能看清。尺寸以小星点为主，少量中、大星点；色温按所在半径分布，内侧偏暖、外侧偏冷，同时独立随机光晕范围与峰值亮度。这些外观参数与闪烁相位均由固定种子决定。星点位置和镜头路线不变；隐藏页面时暂停，减少动态或静态降级时不启用。强度由 `GALAXY_SCENE_CONFIG.twinkleStrength` 控制。

`GalaxyCoreHaloConfig` 集中控制首页星核光晕，默认7秒呼吸、外围范围±3%、亮度±4%、24秒流动节奏和种子888。`galaxy-twinkle.js` 在内存中扩展实际银河光盘的材质，为暖金色外围启用两层平滑噪声，最大UV扰动为纹理尺寸的1.2%。此前只处理index 0的版本动到了一个局部点精灵，未使主体金色光雾流动；现已改用光盘的暖色遮罩，保护白色中心、蓝色外臂和最外缘。原始粒子的坐标、尺寸、颜色数据以及镜头光斑和贴图文件保持原样，独立星点继续闪烁。动画复用已有时钟及光盘的3D位置、缩放和可见状态。首页适配层还修正旧版窗口缩放时重复乘像素倍率的问题，维持入场时的亮星尺度。嵌入场景的`data-core-halo`和`data-core-halo-pose`提供状态，独立原站入口不安装这些扩展。

外围明亮金色光团也加入错峰呼吸：`warmGlowEnabled`控制运行时的原生粒子光晕扩展，默认范围±6%、亮度±14%，周期7秒。暖色色温与空间遮罩覆盖16,012个粒子，固定种子的平滑空间噪声决定各处相位，附近光团变化连贯、远处分散错开。只扰动粒子外围的纹理采样和亮度，中心白光、粒子位置与屏幕尺寸保持稳定。与底层光雾、240个独立亮星共用动画时钟；状态见`data-warm-glows`。全部原始脚本、着色器文件和资源哈希仍保持不变，独立副本保留原效果。实际隔离录像与完整首页录像见`docs/design-references/landing-warm-glows-isolated.mp4`和`landing-warm-glows-home.mp4`。

首页首屏还迁移了 cc888.ai 的流星组件：滑落、爆光、模型图标与名称从中心逐字展开，再停留淡出。光效采用暖白、香槟金及少量淡紫，模型文字为白色、图标保留品牌原色；配色通过组件内CSS变量集中管理，迁移脚本同步复现。使用原站50个展示模型和13个本地SVG图标；展示名单独立于工作区目录，不请求原站接口。原生12组关键帧保留，银河入场完成后300ms启动，桌面第二条间隔600ms，之后每1600–2800ms尝试生成，单条4600–5400ms。桌面最多4条，落点围绕左下文案，位于标题上方和文案右侧；1024px以下最多1条、字号12px，集中在标题上方。按文案位置和标签宽度计算落点，避开导航、正文、按钮和其他标签，窗口变化时重新计算。离开首屏和切换后台时冻结动画与定时器剩余时间，恢复后不补播；离开首页时清理全部任务、观察器及监听器。减少动态、强制静态与银河静态降级不播放。组件状态可通过`.landing-model-meteors`的`data-state`、`data-active-count`、`data-pending-timers`和`data-armed-timers`检查。配置：`lib/model-meteor-config.ts`；来源、原始文件和哈希：`docs/research/cc888-meteors/`。

首页支持中文和English，使用右上角语言菜单切换。五个内容区块、导航、七类弹窗、表单校验及提交状态、99个作品的名称与统计、50个流星模型名称、浏览数、页面标题和描述均随语言切换；刷新后保留选择。界面翻译位于`lib/landing-i18n.ts`，作品翻译位于`lib/landing-showcase-data.json`，复用原有偏好持久化；资产ID、图片、模型图标和业务数据保持原值。英文文案的换行适配手机，语言切换不会重新播放银河入场。该轮只补齐首页语言，工作区开发仍暂停。

第二屏采用左侧文案、模型围绕中央星群，标题为“主流模型，一个入口”，与首屏复用相同的开始使用按钮；手机为上文案、下星群。全Landing已移除装饰性小标题及短横线，正式标题与卡片功能标签保留。模型星群复用原50个中英文展示模型与13个本地品牌图标，桌面/平板/手机最多8/6/4个，固定落点独立闪烁，周期3.5–6.5秒，8–12秒后在暗相位轮换模型，100ms淡出、100ms淡入。离屏与后台暂停，静态模式固定展示；语言切换不重建模型队列。实际录像：`docs/design-references/landing-model-stars.mp4`，预览截图：`landing-model-stars-preview.jpg`。工作区继续暂停。
